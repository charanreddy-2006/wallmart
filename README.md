# Walmart Market Analysis Dashboard | Power BI

**Remark:** 📊 This project showcases an interactive Power BI dashboard designed to monitor Walmart market performance across transactions, profitability, returns, product brands, geographic distribution, and revenue trends. The dashboard demonstrates how business intelligence and data visualization can transform business data into meaningful insights for decision-making.

🚀 Excited to present my Walmart Market Analysis Dashboard, developed using Microsoft Power BI. This project focuses on creating a consolidated business intelligence report that helps monitor key performance indicators, compare product-brand performance, analyze revenue trends, and evaluate performance against business targets.

## 🔍 Project Objectives

1. Track key performance indicators, including Total Transactions, Total Profit, Total Returns, and Revenue vs. Target.
2. Analyze product-brand performance using transaction volume, profitability, profit margin, and return rate.
3. Visualize geographic distribution across the United States, Canada, and Mexico.
4. Monitor weekly revenue trends and identify variations in performance over time.
5. Compare current-month performance against defined targets.
6. Present business metrics through a clear, interactive dashboard for easier interpretation.

## 💡 Key Features Implemented in Power BI

### 🔹 KPI Cards

Created KPI visuals to monitor:

- Current Month Transactions
- Current Month Profit
- Current Month Returns

The cards display actual values alongside target comparisons, helping users quickly assess performance.

### 🔹 Product Brand Performance Matrix

Developed a detailed table to compare individual product brands using:

- Total Transactions
- Total Profit
- Profit Margin
- Return Rate

Applied data bars and conditional formatting to make differences in transaction volume, profitability, and return rates easier to identify.

### 🔹 Interactive Geographic Map

Implemented a map visualization to explore geographic distribution across the United States, Canada, and Mexico.

Country selection controls allow users to focus on individual markets and examine the locations represented in the report.

### 🔹 Weekly Revenue Trend

Created a column chart to visualize revenue trends over time.

The chart supports time-based analysis, allowing users to compare revenue levels across reporting periods and identify changes in performance.

### 🔹 Revenue vs. Target Gauge

Developed a gauge visual to compare the displayed revenue value against a defined target.

This provides a quick overview of revenue performance relative to the selected benchmark.

## 📸 Dashboard Preview

The dashboard brings together KPI cards, product-brand analysis, geographic visualization, weekly revenue trends, and target tracking in a single report.
